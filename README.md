# Equipe-Chaos
Este repositório contém o código-fonte, diagramas UML, testes e documentações do Simulador de Batalha PokeSal (UCSal Pituaçu). O sistema simula um torneio onde treinadores escolhem seus Pokésals iniciais e batalham em turnos, considerando atributos base, vantagens elementais e mecânicas especiais do terreno do estacionamento.
